# 🖥️ Proyecto CorePC: Módulo de Inventario y Gestión

> Documentación técnica oficial del sistema de gestión, armado de equipos y control de stock para CorePC. Trabajo Práctico Integrador - UTN.

---

## 📋 Descripción del Sistema
CorePC es una solución integral diseñada para automatizar y optimizar el flujo de trabajo en el armado y comercialización de equipos informáticos personalizados. Este módulo abarca desde la recepción de requerimientos del cliente por parte del **Asesor de Ventas**, la validación automatizada de componentes mediante el **Módulo de Sistema**, hasta la ejecución técnica en el taller de la mano del **Técnico Ensamblador**.
